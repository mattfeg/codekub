# Sequência de Sequência

O enunciado está no beecrowd: aperte `o` para abri-lo no navegador.

<https://resources.beecrowd.com/repository/UOJ_2028.html>

Os testes são só os exemplos do enunciado: passar neles não garante que a
solução esteja certa no beecrowd.

## Exemplos

Entrada:

```
0
1
2
3
```

Saída:

```
Caso 1: 1 numero
0

Caso 2: 2 numeros
0 1

Caso 3: 4 numeros
0 1 2 2

Caso 4: 7 numeros
0 1 2 2 3 3 3

```
