# Salário com Bônus

O enunciado está no beecrowd: aperte `o` para abri-lo no navegador.

<https://resources.beecrowd.com/repository/UOJ_1009.html>

Os testes são só os exemplos do enunciado: passar neles não garante que a
solução esteja certa no beecrowd.

## Exemplos

Entrada:

```
JOAO
500.00
1230.30
```

Saída:

```
TOTAL = R$ 684.55
```

Entrada:

```
PEDRO
700.00
0.00
```

Saída:

```
TOTAL = R$ 700.00
```

Entrada:

```
MANGOJATA
1700.00
1230.50
```

Saída:

```
TOTAL = R$ 1884.58
```
