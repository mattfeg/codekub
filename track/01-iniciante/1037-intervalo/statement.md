# Intervalo

O enunciado está no beecrowd: aperte `o` para abri-lo no navegador.

<https://resources.beecrowd.com/repository/UOJ_1037.html>

Os testes são só os exemplos do enunciado: passar neles não garante que a
solução esteja certa no beecrowd.

## Exemplos

Entrada:

```
25.01
```

Saída:

```
Intervalo (25,50]
```

Entrada:

```
25.00
```

Saída:

```
Intervalo [0,25]
```

Entrada:

```
100.00
```

Saída:

```
Intervalo (75,100]
```

Entrada:

```
-25.02
```

Saída:

```
Fora de intervalo
```
