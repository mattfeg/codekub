# Entrada e Saída de Números Reais

O enunciado está no beecrowd: aperte `o` para abri-lo no navegador.

<https://resources.beecrowd.com/repository/UOJ_2758.html>

Os testes são só os exemplos do enunciado: passar neles não garante que a
solução esteja certa no beecrowd.

## Exemplos

Entrada:

```
1.2 3.45
3.451 3.4516
```

Saída:

```
A = 1.200000, B = 3.450000
C = 3.451000, D = 3.451600
A = 1.2, B = 3.5
C = 3.5, D = 3.5
A = 1.20, B = 3.45
C = 3.45, D = 3.45
A = 1.200, B = 3.450
C = 3.451, D = 3.452
A = 1.200E+00, B = 3.450E+00
C = 3.451E+00, D = 3.452E+00
A = 1, B = 3
C = 3, D = 3
```
