# Aumento de Salário

O enunciado está no beecrowd: aperte `o` para abri-lo no navegador.

<https://resources.beecrowd.com/repository/UOJ_1048.html>

Os testes são só os exemplos do enunciado: passar neles não garante que a
solução esteja certa no beecrowd.

## Exemplos

Entrada:

```
400.00
```

Saída:

```
Novo salario: 460.00
Reajuste ganho: 60.00
Em percentual: 15 %
```

Entrada:

```
800.01
```

Saída:

```
Novo salario: 880.01
Reajuste ganho: 80.00
Em percentual: 10 %
```

Entrada:

```
2000.00
```

Saída:

```
Novo salario: 2140.00
Reajuste ganho: 140.00
Em percentual: 7 %
```
