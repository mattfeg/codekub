# Entrada e Saída de String

O enunciado está no beecrowd: aperte `o` para abri-lo no navegador.

<https://resources.beecrowd.com/repository/UOJ_2760.html>

Os testes são só os exemplos do enunciado: passar neles não garante que a
solução esteja certa no beecrowd.

## Exemplos

Entrada:

```
Roberto
Carlos
Aldo
```

Saída:

```
RobertoCarlosAldo
CarlosAldoRoberto
AldoRobertoCarlos
RobertoCarlosAldo
```
