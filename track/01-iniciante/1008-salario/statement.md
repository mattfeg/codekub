# Salário

O enunciado está no beecrowd: aperte `o` para abri-lo no navegador.

<https://resources.beecrowd.com/repository/UOJ_1008.html>

Os testes são só os exemplos do enunciado: passar neles não garante que a
solução esteja certa no beecrowd.

## Exemplos

Entrada:

```
25
100
5.50
```

Saída:

```
NUMBER = 25
SALARY = U$ 550.00
```

Entrada:

```
1
200
20.50
```

Saída:

```
NUMBER = 1
SALARY = U$ 4100.00
```

Entrada:

```
6
145
15.55
```

Saída:

```
NUMBER = 6
SALARY = U$ 2254.75
```
