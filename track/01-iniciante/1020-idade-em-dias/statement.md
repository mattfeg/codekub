# Idade em Dias

O enunciado está no beecrowd: aperte `o` para abri-lo no navegador.

<https://resources.beecrowd.com/repository/UOJ_1020.html>

Os testes são só os exemplos do enunciado: passar neles não garante que a
solução esteja certa no beecrowd.

## Exemplos

Entrada:

```
400
```

Saída:

```
1 ano(s)
1 mes(es)
5 dia(s)
```

Entrada:

```
800
```

Saída:

```
2 ano(s)
2 mes(es)
10 dia(s)
```

Entrada:

```
30
```

Saída:

```
0 ano(s)
1 mes(es)
0 dia(s)
```
