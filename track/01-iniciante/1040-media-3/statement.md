# Média 3

O enunciado está no beecrowd: aperte `o` para abri-lo no navegador.

<https://resources.beecrowd.com/repository/UOJ_1040.html>

Os testes são só os exemplos do enunciado: passar neles não garante que a
solução esteja certa no beecrowd.

## Exemplos

Entrada:

```
2.0 4.0 7.5 8.0
6.4
```

Saída:

```
Media: 5.4
Aluno em exame.
Nota do exame: 6.4
Aluno aprovado.
Media final: 5.9
```

Entrada:

```
2.0 6.5 4.0 9.0
```

Saída:

```
Media: 4.8
Aluno reprovado.
```

Entrada:

```
9.0 4.0 8.5 9.0
```

Saída:

```
Media: 7.3
Aluno aprovado.
```
