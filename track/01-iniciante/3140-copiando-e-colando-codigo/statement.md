# Copiando e Colando Código

O enunciado está no beecrowd: aperte `o` para abri-lo no navegador.

<https://resources.beecrowd.com/repository/UOJ_3140.html>

Os testes são só os exemplos do enunciado: passar neles não garante que a
solução esteja certa no beecrowd.

## Exemplos

Entrada:

```
<html>
<head>
<title>Meu primeiro programa em HTML</title>
</head>
<body>
<h1>Hello World!</h1>
</body>
</html>
```

Saída:

```
<h1>Hello World!</h1>
```
