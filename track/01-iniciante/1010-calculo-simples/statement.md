# Cálculo Simples

O enunciado está no beecrowd: aperte `o` para abri-lo no navegador.

<https://resources.beecrowd.com/repository/UOJ_1010.html>

Os testes são só os exemplos do enunciado: passar neles não garante que a
solução esteja certa no beecrowd.

## Exemplos

Entrada:

```
12 1 5.30
16 2 5.10
```

Saída:

```
VALOR A PAGAR: R$ 15.50
```

Entrada:

```
13 2 15.30
161 4 5.20
```

Saída:

```
VALOR A PAGAR: R$ 51.40
```

Entrada:

```
1 1 15.10
2 1 15.10
```

Saída:

```
VALOR A PAGAR: R$ 30.20
```
