# Entrada e Saída de Números Inteiros

O enunciado está no beecrowd: aperte `o` para abri-lo no navegador.

<https://resources.beecrowd.com/repository/UOJ_2757.html>

Os testes são só os exemplos do enunciado: passar neles não garante que a
solução esteja certa no beecrowd.

## Exemplos

Entrada:

```
1234
12
123
```

Saída:

```
A = 1234, B = 12, C = 123
A =       1234, B =         12, C =        123
A = 0000001234, B = 0000000012, C = 0000000123
A = 1234      , B = 12        , C = 123
```
