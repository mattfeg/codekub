# Antecessor e sucessor

Todo número inteiro tem um vizinho logo antes e outro logo depois. Dado um
número, mostre os dois.

## Entrada

Um inteiro `N` (−10⁹ ≤ N ≤ 10⁹).

## Saída

Imprima duas linhas:

```
antecessor: <N - 1>
sucessor: <N + 1>
```

## Exemplos

Entrada:

```
10
```

Saída:

```
antecessor: 9
sucessor: 11
```

Entrada:

```
0
```

Saída:

```
antecessor: -1
sucessor: 1
```
