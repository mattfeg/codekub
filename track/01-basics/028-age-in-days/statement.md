# Idade em dias

Quantos dias você já viveu? Para simplificar, considere que todo ano tem 365
dias e todo mês tem 30 dias.

## Entrada

Uma linha com três inteiros: anos `A` (0 ≤ A ≤ 120), meses `M` (0 ≤ M ≤ 11)
e dias `D` (0 ≤ D ≤ 29).

## Saída

Imprima `dias vividos: ` seguido do total de dias.

## Exemplos

Entrada:

```
20 3 15
```

Saída:

```
dias vividos: 7405
```

Entrada:

```
0 0 0
```

Saída:

```
dias vividos: 0
```
