# Saudação

O codekub quer dar boas-vindas a cada pessoa que chega, pelo nome.

## Entrada

Uma linha com o nome da pessoa: de 1 a 50 caracteres, podendo ter espaços
(por exemplo, nome e sobrenome).

## Saída

Imprima `Olá, NOME! Boas-vindas ao codekub.`, trocando `NOME` pelo nome lido.

## Exemplos

Entrada:

```
Ana
```

Saída:

```
Olá, Ana! Boas-vindas ao codekub.
```

Entrada:

```
João Pedro
```

Saída:

```
Olá, João Pedro! Boas-vindas ao codekub.
```
