# O elefante

> **Chefão** · nota 800 no Codeforces

Um elefante decidiu visitar um amigo. A casa do elefante fica no ponto `0` de
uma reta, e a casa do amigo fica no ponto `x` (com `x > 0`). A cada passo, o
elefante pode avançar 1, 2, 3, 4 ou 5 posições.

Qual é o **menor número de passos** para o elefante chegar à casa do amigo?

## Entrada

Um inteiro `x` (1 ≤ x ≤ 1000000), a posição da casa do amigo.

## Saída

Imprima o menor número de passos que o elefante precisa dar para ir do ponto
`0` ao ponto `x`.

## Exemplos

Entrada:

```
5
```

Saída:

```
1
```

Entrada:

```
12
```

Saída:

```
3
```

## Observação

No primeiro exemplo, basta um passo de tamanho 5. No segundo, o elefante pode
andar 3, depois 5, depois 4. Há outras formas de chegar em 3 passos, mas não dá
para chegar em menos.
