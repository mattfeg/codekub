# Desconto à vista

Uma loja dá desconto para quem paga à vista. Dado o preço de um produto e a
porcentagem de desconto, calcule quanto a pessoa economiza e quanto paga.

## Entrada

Uma linha com o preço `P`, um real com duas casas (0.01 ≤ P ≤ 100000), e a
porcentagem de desconto `D`, um inteiro (0 ≤ D ≤ 100).

## Saída

Imprima duas linhas, com valores de duas casas decimais:

```
Desconto: R$ <P × D / 100>
Total: R$ <P menos o desconto>
```

## Exemplos

Entrada:

```
200.00 10
```

Saída:

```
Desconto: R$ 20.00
Total: R$ 180.00
```

Entrada:

```
59.90 20
```

Saída:

```
Desconto: R$ 11.98
Total: R$ 47.92
```
