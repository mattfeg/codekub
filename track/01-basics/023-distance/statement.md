# Distância entre pontos

No plano cartesiano, a distância entre os pontos `(x1, y1)` e `(x2, y2)` é

```
d = √((x2 − x1)² + (y2 − y1)²)
```

## Entrada

Duas linhas. A primeira tem as coordenadas `x1 y1` do primeiro ponto e a
segunda tem `x2 y2` do segundo. Todas são números reais entre −1000 e 1000,
com uma casa decimal.

## Saída

Imprima a distância com **quatro** casas decimais.

## Exemplos

Entrada:

```
0.0 0.0
3.0 4.0
```

Saída:

```
5.0000
```

Entrada:

```
1.5 -2.0
-0.5 3.0
```

Saída:

```
5.3852
```

## Dica

Procure a função de raiz quadrada da sua linguagem. Ela costuma ficar em um
módulo de matemática.
