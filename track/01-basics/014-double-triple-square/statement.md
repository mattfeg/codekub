# Dobro, triplo e quadrado

Dado um número inteiro, calcule o dobro, o triplo e o quadrado dele.

## Entrada

Um inteiro `N` (−10⁴ ≤ N ≤ 10⁴).

## Saída

Imprima três linhas:

```
dobro: <2 × N>
triplo: <3 × N>
quadrado: <N × N>
```

## Exemplos

Entrada:

```
7
```

Saída:

```
dobro: 14
triplo: 21
quadrado: 49
```

Entrada:

```
-3
```

Saída:

```
dobro: -6
triplo: -9
quadrado: 9
```
