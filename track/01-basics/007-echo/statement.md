# Eco

Um eco repete exatamente o que ouve. Seu programa vai fazer o mesmo com o
texto que receber.

## Entrada

Uma única linha com um texto de 1 a 100 caracteres. O texto pode ter letras,
acentos, números, espaços e pontuação, mas não começa nem termina com espaço.

## Saída

Imprima o mesmo texto, sem nenhuma alteração.

## Exemplos

Entrada:

```
Olá, codekub!
```

Saída:

```
Olá, codekub!
```

Entrada:

```
Aprender a programar é praticar todo dia
```

Saída:

```
Aprender a programar é praticar todo dia
```

## Observação

Leia a linha **inteira**. Algumas formas de leitura param no primeiro espaço e
pegariam só a palavra `Aprender`.
