# Média ponderada

Em uma disciplina, a nota final combina duas provas e um projeto. O projeto
pesa mais:

| Avaliação | Peso |
|-----------|------|
| Prova 1   | 3    |
| Prova 2   | 3    |
| Projeto   | 4    |

A média ponderada é a soma de cada nota multiplicada pelo seu peso, dividida
pela soma dos pesos (10).

## Entrada

Uma linha com três números reais, as notas da prova 1, da prova 2 e do
projeto, cada uma entre 0.0 e 10.0, com uma casa decimal.

## Saída

Imprima `Média final: ` seguido da média com **uma** casa decimal.

## Exemplos

Entrada:

```
7.0 8.0 6.5
```

Saída:

```
Média final: 7.1
```

Entrada:

```
10.0 10.0 10.0
```

Saída:

```
Média final: 10.0
```
