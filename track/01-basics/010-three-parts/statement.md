# Três parcelas

Uma compra foi paga em três parcelas. Descubra o valor total pago.

## Entrada

Três linhas, cada uma com um inteiro `P` (0 ≤ P ≤ 10⁶): o valor, em reais,
de cada parcela.

## Saída

Imprima `Total: R$ X`, onde `X` é a soma das três parcelas.

## Exemplos

Entrada:

```
100
250
75
```

Saída:

```
Total: R$ 425
```

Entrada:

```
0
0
1
```

Saída:

```
Total: R$ 1
```

## Observação

Agora cada número vem em **uma linha diferente**. Repare como isso muda a
forma de ler a entrada em relação ao exercício anterior.
