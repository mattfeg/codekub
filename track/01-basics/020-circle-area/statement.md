# Área do círculo

Calcule a área de um círculo a partir do raio. Use a fórmula `A = π × R²`,
com `π = 3.14159`.

## Entrada

Um número real `R` (0 < R ≤ 10000), com até duas casas decimais.

## Saída

Imprima `A = ` seguido da área com **quatro** casas decimais.

## Exemplos

Entrada:

```
2.00
```

Saída:

```
A = 12.5664
```

Entrada:

```
0.50
```

Saída:

```
A = 0.7854
```

## Observação

Use exatamente `π = 3.14159`, e não a constante da sua linguagem: valores de
π com mais casas mudam os últimos dígitos do resultado.
