# Soma

Leia dois números inteiros e imprima a soma deles.

## Entrada

Uma linha com dois inteiros `A` e `B`, separados por um espaço
(−10⁹ ≤ A, B ≤ 10⁹).

## Saída

Imprima uma linha com o valor de `A + B`.

## Exemplos

Entrada:

```
3 5
```

Saída:

```
8
```

Entrada:

```
-700 250
```

Saída:

```
-450
```

## Observação

Os dois números vêm na **mesma linha**. Você vai precisar separá-los antes de
convertê-los para inteiros.
