# Lista de Nomes

O enunciado está no beecrowd: aperte `o` para abri-lo no navegador.

<https://resources.beecrowd.com/repository/UOJ_3135.html>

Os testes são só os exemplos do enunciado: passar neles não garante que a
solução esteja certa no beecrowd.

## Exemplos

Entrada:

```
12
sergio
ana
maria
carlos
eva
joaquim
jo
mara
laura
lucas
ari
paulo
```

Saída:

```
jo, ana, mara, maria, sergio, joaquim
eva, laura, carlos
ari, lucas
paulo
```
