# Ano Bissexto ou Ano não Bissexto

O enunciado está no beecrowd: aperte `o` para abri-lo no navegador.

<https://resources.beecrowd.com/repository/UOJ_1279.html>

Os testes são só os exemplos do enunciado: passar neles não garante que a
solução esteja certa no beecrowd.

## Exemplos

Entrada:

```
2000
3600
4515
2001
```

Saída:

```
This is leap year.

This is leap year.
This is huluculu festival year.

This is huluculu festival year.

This is an ordinary year.
```
