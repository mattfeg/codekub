# Velocidade Média

O enunciado está no beecrowd: aperte `o` para abri-lo no navegador.

<https://resources.beecrowd.com/repository/UOJ_1304.html>

Os testes são só os exemplos do enunciado: passar neles não garante que a
solução esteja certa no beecrowd.

## Exemplos

Entrada:

```
00:00:01 100
00:15:01
00:30:01
01:00:01 50
03:00:01
03:00:05 140
```

Saída:

```
00:15:01 25.00 km
00:30:01 50.00 km
03:00:01 200.00 km
```
