# Sobrenome Não é Fácil

O enunciado está no beecrowd: aperte `o` para abri-lo no navegador.

<https://resources.beecrowd.com/repository/UOJ_3358.html>

Os testes são só os exemplos do enunciado: passar neles não garante que a
solução esteja certa no beecrowd.

## Exemplos

Entrada:

```
6
Ferrari
Bianchi
Hoffmann
Hofmann
Lewandowski
Nowak
```

Saída:

```
Ferrari eh facil
Bianchi nao eh facil
Hoffmann nao eh facil
Hofmann eh facil
Lewandowski nao eh facil
Nowak eh facil
```
