# Faixa de Letras

O enunciado está no beecrowd: aperte `o` para abri-lo no navegador.

<https://resources.beecrowd.com/repository/UOJ_1276.html>

Os testes são só os exemplos do enunciado: passar neles não garante que a
solução esteja certa no beecrowd.

## Exemplos

Entrada:

```
aha
xyzzy
quick brown fox jumps over the lazy dog
fbxeac
x
b z a x c y
bdfhjlnprtvxz
az def
```

Saída:

```
a:a, h:h
x:z
a:z
a:c, e:f, x:x
x:x
a:c, x:z
b:b, d:d, f:f, h:h, j:j, l:l, n:n, p:p, r:r, t:t, v:v, x:x, z:z
a:a, d:f, z:z
```
