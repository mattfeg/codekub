# Banco de Dados de Clientes

O enunciado está no beecrowd: aperte `o` para abri-lo no navegador.

<https://resources.beecrowd.com/repository/UOJ_2906.html>

Os testes são só os exemplos do enunciado: passar neles não garante que a
solução esteja certa no beecrowd.

## Exemplos

Entrada:

```
2
two.different.providers@now.here
two.different.providers@nowhere
```

Saída:

```
2
```

Entrada:

```
2
1.2.3@testing
testing@1.2.3
```

Saída:

```
2
```

Entrada:

```
7
alice@e.mail
eve@another.mail
bob@e.mail
joe90@e.mail
b.o.b@e.mail
bob+new@e.mail
bob@another.provider
```

Saída:

```
5
```
