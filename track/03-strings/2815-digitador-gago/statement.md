# Digitador Gago

O enunciado está no beecrowd: aperte `o` para abri-lo no navegador.

<https://resources.beecrowd.com/repository/UOJ_2815.html>

Os testes são só os exemplos do enunciado: passar neles não garante que a
solução esteja certa no beecrowd.

## Exemplos

Entrada:

```
Juca comprou fafarinha na memercearia e papagou 4 reais o quilo. A mamae de Juca pediu para ele comprar mamais 2 quilos.
```

Saída:

```
Juca comprou farinha na mercearia e pagou 4 reais o quilo. A mae de Juca pediu para ele comprar mais 2 quilos.
```
