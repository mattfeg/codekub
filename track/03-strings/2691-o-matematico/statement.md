# O Matemático

O enunciado está no beecrowd: aperte `o` para abri-lo no navegador.

<https://resources.beecrowd.com/repository/UOJ_2691.html>

Os testes são só os exemplos do enunciado: passar neles não garante que a
solução esteja certa no beecrowd.

## Exemplos

Entrada:

```
1
4x5
```

Saída:

```
4 x 5 = 20 && 5 x 5 = 25
4 x 6 = 24 && 5 x 6 = 30
4 x 7 = 28 && 5 x 7 = 35
4 x 8 = 32 && 5 x 8 = 40
4 x 9 = 36 && 5 x 9 = 45
4 x 10 = 40 && 5 x 10 = 50
```
