# Operações em ABP I

O enunciado está no beecrowd: aperte `o` para abri-lo no navegador.

<https://resources.beecrowd.com/repository/UOJ_1200.html>

Os testes são só os exemplos do enunciado: passar neles não garante que a
solução esteja certa no beecrowd.

## Exemplos

Entrada:

```
I c
I f
I a
I h
INFIXA
PREFIXA
POSFIXA
P z
P h
I g
INFIXA
```

Saída:

```
a c f h
c a f h
a h f c
z nao existe
h existe
a c f g h
```
